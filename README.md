# 살아있는 왕국 v0.7

NPC가 플레이어의 지시 없이 스스로 생활하는 판타지 마을 시뮬레이션입니다.

## 웹게임
https://kkhkkh20-bit.github.io/everworld-game/

> GitHub Pages가 아직 활성화되지 않았다면 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 먼저 선택해야 합니다. Actions 탭에서 Deploy game to GitHub Pages가 성공했는지도 확인하세요.

## 핵심 기능

- 접속하면 즉시 자동 진행되는 왕국. 조작할 필요가 없습니다.
- 30명 시작, 무작위 NPC 직책·성격·목표·경제 상황
- 주민 간 거래, 사기, 절도, 싸움, 체포, 사망
- 피해 상대/수법을 기억하고 반복 사기를 경계
- 주기적 이주, 왕위 교체, 왕의 도주 또는 새 국왕 등장
- 주민을 눌러 정보/기억 확인, 특정 인물을 추적
- 1/3/8배속 및 일시 정지, 새 세계 생성
- 브라우저 내 저장. 다시 열면 세계를 복원하고 부재 시간 일부를 시뮬레이션합니다.

## 실행과 한계

`index.html`만 있는 정적 웹게임입니다. 별도 서버 API나 로그인은 필요하지 않습니다.
시뮬레이션은 **웹페이지가 열려 있는 동안** 실행되며, 닫혀 있을 때는 별도 서버에서 상시 계산하지 않습니다.
다시 접속하면 저장한 상태에서 제한적인 시간 경과를 재현합니다.
자유행동 플레이어 모드는 아직 구현되지 않은 관찰 중심 시제품입니다.

## 개발 방향

다음 단계는 NPC의 계획 수립과 사건 연쇄, 외국 세력, 상속, 실제 플레이어 개입을 순서대로 고도화하는 것입니다.
