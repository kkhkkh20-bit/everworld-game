# 살아있는 왕국 — Everworld v0.9

판타지 세계의 주민들은 플레이어가 개입하지 않아도 스스로 일하고, 생존하며, 사건을 벌이는 영속 사회 시뮬레이션입니다.

## 실행
- 게임: https://kkhkkh20-bit.github.io/everworld-game/
- 자동 실행되며 일시정지와 배속을 지원합니다.
- 기본 화면은 직책표이고 '지도' 버튼으로 지도를 볼 수 있습니다.
- 주민을 클릭하면 직책, 개인 목표, 체력, 허기, 수입·지출, 관계에 따른 행동 정보를 볼 수 있습니다.

## 사회 구조
- 국왕: 재상·귀족의 충성도와 능력에 따라 통치 효율과 스트레스가 달라집니다.
- 재상: 세금을 걷고 국고를 관리합니다. 성격에 따라 횡령 가능성이 있습니다.
- 치안대: 치안대장이 대원들을 지휘하며 사건 신고와 증거를 근거로 수사·체포합니다.
- 민간 직업: 농부, 상인, 광부, 대장장이, 여관주인, 치료사 등은 본업으로 수입을 벌며 생산·거래에 참여합니다.
- 도적도 생존 비용을 감당해야 하며, 성격에 따라 절도나 약탈을 시도합니다.

## 생존 경제
- NPC는 임금, 거래, 국고 지원 등 서로 다른 경로에서 수입을 얻습니다.
- 매일 식비·주거비를 지급하고 5일마다 의복 유지비를 냅니다.
- 먹지 못하면 허기와 스트레스가 증가하고 체력이 떨어져 사망할 수 있습니다.
- 노숙이 이어져도 체력에 불이익이 발생합니다.
- 국고는 근로소득 세금 등을 재원으로 왕실 및 치안 직무의 급여를 지급합니다.
- 식량 생산 부족 시 시장과 국고의 외부 구매로 재고를 보충할 수 있습니다.
- 주민 사망 시 해당 직책은 공석이 되며 후임은 일정 시간 후 선발될 수 있습니다.

## 검증
- 시드 6개를 각 90일 자동 시뮬레이션해 NPC 업무 반복, 출생 대신 이주, 사망, 수사·체포, 공석을 확인했습니다.
- 강제 빈곤·식량 단절 상황을 만들어 허기·체력 저하와 사망 판정을 확인했습니다.

## 기술
단일 `index.html` 정적 웹게임. `main` 변경 시 GitHub Actions에서 Pages 자동 배포합니다.
시뮬레이션은 현재 브라우저에서 돌아가며 전체 클라우드 서버에서 실시간 상시 운영되는 것은 아닙니다.

## v1.0: 심시티식 주민 생활 관찰

- 처음 접속하면 **마을 지도**가 열립니다. 오른쪽 사건 피드와 하단 실시간 인구 현황을 함께 볼 수 있습니다.
- NPC마다 근무 장소와 거처가 지정됩니다. 이른 아침 출근, 낮 본업, 저녁 시장·여관 방문 및 교류, 밤 귀가·수면을 자율적으로 실행합니다.
- 이웃끼리 친해지거나 말다툼하고, 곤란한 사람에게 금전 지원을 하며, 관계 기억이 누적됩니다.
- 주민 클릭 시 현재 행동, 집과 일터, 성격, 개인 목표를 확인할 수 있습니다.
- 지도에는 장소별 실제 인원과 근무 상황을 표시합니다. **직책표** 버튼을 눌러 국왕·치안대·공석 현황으로 돌아갈 수 있습니다.
- 기존 규칙의 본업 수입, 의식주 지출, 굶주림 사망, 범죄 수사, 사망·이주는 계속 적용됩니다.

개별 집을 물리적으로 소유하거나 길찾기 충돌을 해결하는 본격 도시건설 게임은 아직 구현되지 않았습니다. 현재는 고정된 9개 장소 사이를 이동하는 규칙 기반 소규모 자율생활 시뮬레이션입니다.
