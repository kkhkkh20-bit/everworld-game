# 마을·인물 요약과 상세 카드

세계 지도의 마을 또는 상단 마을 이름을 누르면 인구, 상비 병력, 공동 금고, 식량 비축 일수, 주택, 영토가 한 카드에 표시된다. 통치 주체와 소속 세력, 진행 중인 전쟁도 확인할 수 있다. 실제 인물 통치자는 인물 카드로 연결한다. 개인 통치자 기록이 없는 공동체는 주민 자치회/개인 통치자 미지정으로 표시한다.

자세히 보기에는 자재, 성벽, 병영, 군사 숙련, 원정·동원 가능 병력, 배움터, 동맹, 진행 공사가 나온다. 역사·군사·생활·교류 메뉴를 상세 카드에서 연결한다. 상비 병력은 들녘의 실제 경비병 수이며 동원 가능 인원과 구분한다.

인물 요약은 개인 금화와 가구 금화를 구분하고, 건강·현재 위치·현재 행동·신분을 표시한다. 상세에는 기력·허기·스트레스·직업 숙련과 가구 자산·부채·거처·목표가 나온다. 능력·성격·기술은 펼침 항목으로 제공하며 갱신 시 펼침 상태를 보존한다. 원천 데이터가 없는 이웃 주민의 개인 돈·능력은 임의 수치를 만들지 않고 미집계라고 표시한다.

`PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/inspection-cards.cjs`는 모바일 터치, 정확한 통치자·금고·인구, 개인/가구 금화 구분, 상세 이동, 능력치 표시와 펼침 상태, 요약의 스크롤 없는 배치, 이웃 자료 한계 및 상단 마을 이름 진입을 확인한다. 기존 플레이 리뷰의 교류 진입 경로도 상세 카드에 맞춰 갱신했다.
