# 살아있는 왕국 v2.6 — 가문과 통치 제도의 자율 발전 검증

## 세계 설정
- 왕국력 1840년: 중세풍 소규모 농경 공동체. 왕과 백작 없이 **촌장**과 마을 가구에서 시작
- 현실의 1840년 유럽 역사와 무관한 판타지 연호
- 각 NPC의 부모·자녀·배우자 관계, 가문(clanId), 세대(generation), 가문 명칭과 성씨, 생존한 후손 수 추적
- 토지·주택·가축·식량 비축·금화 소유 가구의 자산을 합산해 가문별 영향력과 명성 평가
- 지도자 교체 시 촌장 선출 또는 세습 가문의 후계자를 평가
- 마을 평의회·가문 세습·마을 연합이 물리적 성장, 생산경제, 정통성, 불만과 명성을 고려해 변화
- 시작 시 왕위·왕족·봉건 등급 없음. 군 단위 세습 지도 체제가 성립해야 ‘백작’ 호칭 사용
- 부유한 가문의 권력 세습이 필수 아님: 평의회와 주민 대표 선출 제도 존속 가능
- 분리 취락이 생긴 뒤 여러 공동체가 연합하거나 군을 이루며 단계적으로 범위 확장

## 이번 UI
게임 내 **가문·정치** 탭으로 현재 지도자와 통치제, 정통성, 취락 수, 지도자 연혁, 개별 가문 명성·재산·생존 구성원·최대 세대 확인.

## 주의와 개선 과제
1. 현재 ‘백작’은 세습 통치가 정착된 군 단위 대표에게 붙는 **칭호**임. 영지의 봉신관계, 작위 수여권, 여러 영주를 거느리는 봉건 정치 실체는 아직 미구현.
2. 마을 연합 형성은 경제·인구·자원 제약을 갖지만, 취락 간 별도 자치의회와 물리적 생산망은 아직 단순화됨.
3. 가문 간 혼인을 통한 혈연 연결과 세대별 상속은 구현됐지만, 귀족 집안의 정략결혼, 복잡한 친족 혈통표와 입양·양자제는 아직 없음.
4. 향후 50~100년 시험에서 인구 수용력 상한·개간 제한·농업 위기·자녀의 생존이 정치 제도 형성보다 과도하게 작용할 수 있음.
5. 계승 경쟁과 분열, 군 단위 행정세 징수, 영지와 봉신, 제도 변경을 위한 명확한 의회 의결 등은 더 정교하게 만들 필요가 있음.
6. 정해진 ‘왕국’ 달성 목표는 두지 않음. 세습제가 무너져도 공화적 평의회로 돌아갈 수 있게 유지하는 것이 설계 원칙.
