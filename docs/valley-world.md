# 산들계곡 — 후속 마을의 관리자

현재 사용자 요청은 다른 마을들이 이미 살아가는 세계 안에서 약한 후속 마을의 관리자가 되는 자동 시뮬레이션이다. 개별 캐릭터 직접 조작 모드는 보존하되, 기본 진입은 이 세계로 바꿨다.

## 시작과 성장

- 다섯 기존 정착지를 동일한 생산·운반·건설·교역 규칙으로 180일 먼저 운영한다. 초기 주거와 시설에서 출발해, 이 기간에 추가된 건물과 사건은 실제로 진행한 시뮬레이션 결과다. 이 기간에 현재 플레이어 마을은 없다.
- 시작 시 모촌 오크헤이븐에서 주민 12명과 곡물 30·목재 24·석재 10을 실제 차감해 버들나루를 세운다. 모든 마을의 인구 합계는 모촌 분리 전후에 보존된다.
- 버들나루는 회관 텐트와 주택 하나로 시작한다. 같은 규칙에 따라 식량을 확보하고 농장·주택·작업장·풍차·시장을 계획한다. 관리자는 우선순위와 비축 목표, 다음 공사, 교역 및 이민 수용을 정한다.
- 이웃 정착지의 생산·소비·작업조·공사·교역·출생도 같은 시계에서 계속된다. 현재 선택한 마을이나 카메라 위치는 시뮬레이션에 관여하지 않는다.
- 모촌의 추가 이주도 인구를 실제로 옮긴다. 주거와 식량 조건이 맞지 않으면 이주하지 않는다.

## 모델과 보존 법칙

`js/valley-engine.js`는 DOM/WebGL 없이 실행한다. 각 마을은 주민 집계와 여섯 작업조를 가진다. 인구 전체를 각각의 독립 인물로 가장하지 않으며, 지도 인물과 패널은 작업조임을 명시한다. 생산 규모는 작업조의 크기·시설·정착지 입지에 따른다. 숲은 벌목으로 줄고 회복한다. 항구·성채·농촌·숲 마을의 생산 여건이 다르므로 물자 수요와 교역도 달라진다.

- 자원은 작업장에서 작업한 뒤 손짐으로 창고까지 운반되어야 재고가 증가한다.
- 건설 자재는 창고에서 꺼낼 때 차감하고 운반 예약에 잡는다. 현장에 도착한 뒤 자재가 모두 모여야 건설 노동이 진행된다.
- 교역은 곡물 20 ↔ 목재 8의 물물교환이다. 출발 시 양쪽 물자를 차감하고, 도착 때 각 상대에게 지급한다. 귀로까지 실제 수레가 이동한다. 진행 중 거래를 포함해 물자가 보존된다.
- 하루당 주민 1인 곡물 .12를 소비한다. 출생·기근 사망·이주를 별도 집계한다. 식량 비축이 부족하면 성장 방침보다 식량 확보를 우선한다.
- 현재 고정된 여섯 정착지와 마을당 최대 24개 시설의 계곡이다. 전쟁·국가 확장·주민 개인 가족사는 이 모드에 포함하지 않았다. 경제 수치는 역사 자료로 보정된 실증 모델이 아니다.

## 지도와 에셋

Three.js의 직교 카메라로 실제 GLB 모델·그림자·지형·강·교역로를 렌더링한다. KayKit CC0 중세 모델 18종을 내려받았다. 건물과 나무는 같은 형상을 묶어 그리며, 지형·길은 정적으로 유지한다. 건물 추가 때만 건물 배치와 길을 갱신한다. 일시정지 후 카메라가 멈추면 WebGL 다시 그리기를 멈춘다. 성능 수치나 특정 기기 FPS를 보장하지 않는다.

전체 계곡, 마을 확대, 회전, 드래그, 휠/두 손가락 확대, 방향키 카메라 조작을 지원한다. 관리 창은 게임 위에 열리고 닫힌다. 모바일 페이지 스크롤 없이 플레이한다. WebGL 불가 시 오류와 이전 문명 모드 진입을 제공한다. 외부 CDN은 런타임에 사용하지 않는다.

저장 키는 `everworld_valley_v1`. 이전 이세계 저장은 `frontier-isekai.html`, 교역촌은 `frontier-trade.html`, 원래 문명 관찰은 `index.html?classic=1`에 별도로 유지한다.

## 실행과 검증

저장소에서 `python3 -m http.server 8020 --bind 127.0.0.1` 후 `frontier.html`을 연다.

- `node tests/valley.cjs`: 선행 180일의 실제 발전, 인구 보존, 독립 마을 생산·건설·이주, 유효한 정책, 양방향 교역 물자 보존, 저장 재현성, 장기간 유효 재고.
- `node tests/valley-ui.cjs`: 위 서버 및 제공된 Playwright·Chromium 필요. 1440/390/320px에서 18개 모델과 36개 작업조 로딩, 카메라 조작의 상태 불변, 운영 방침·이웃 선택, 자율 성장, 저장 복원, 일시정지 렌더 예산, 화면 스크롤/오류 없음을 확인한다. 소프트웨어 렌더러 검증용 플래그를 쓰며 실제 기기 FPS 측정은 아니다.
- 보존 모드 회귀: `tests/isekai.cjs`, `tests/frontier.cjs`, `tests/simulate.mjs`, `tests/resident-activity.cjs`, `tests/render-budget.cjs` 및 각 브라우저 테스트.
- 기존 `scripts/package-frontier.py`는 보존된 이세계 모드의 단일 HTML 생성 도구로 유지한다. 이 3D 세계는 모듈과 모델을 쓰므로 HTTP 정적 서버 또는 GitHub Pages에서 실행한다.
