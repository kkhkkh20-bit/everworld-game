# 첫 겨울 — 상황을 보고 이웃과 조건을 고르는 과정

이전 리뷰에서는 기본 세계 900일 동안 버들나루의 인구가 12명에 머물고, 첫 주택이 늦으며, 세력 창에서 할 수 있는 행동이 적었다. 이번 작업은 첫 겨울의 생존과 외교 선택을 하나의 과정으로 연결한다. 더 많은 지도·직업·자원을 추가하지 않았다.

## 지도에서 읽는 상황

작은 마을 표시에는 식량 일수와 비축 추세, 인구와 잠자리, 공사 상태를 남긴다. 공사장 위에는 현재 운반·자재 부족·식량 확보 우선 등의 실제 원인을 표시한다. 창고 옆 자루 수는 실제 곡물 재고에 따라 바뀐다. 주택을 갖추면 중심 천막도 주거 형태로 바뀐다. 농장·연결·첫 주택·정착촌 이정표는 실제 완성 후에만 표시한다.

하단 한 줄은 겨울까지 남은 시간, 현재 계획의 진행, 답변할 제안을 알려준다. 큰 창은 눌렀을 때 열린다. 초기에는 세계의 다른 사건보다 버들나루의 이야기를 우선한다. UI를 숨기면 표시 갱신을 쉬고, 수동 답변이 필요할 때 다시 표시한다.

## 세 가지 방침

- **목재로 곡물 교환:** 가까운 상대의 실제 잉여와 현재 교환 비율을 본다. 정찰에 식량 5, 숲길에 목재 12·석재 3과 작업조의 시간이 든다. 길이 열리면 그 상대와 곡물을 반복 교환한다. 회당 승인한 목재 상한을 넘기지 않으며 가격과 상대 재고에 따라 곡물 수량이 달라진다. 첫 교환을 마련하는 동안 주택 자재를 먼저 쓰지 않는다. 그만큼 주거 확장이 늦을 수 있다.
- **보호와 식량 지원:** 이웃에게 길을 열고 보호를 요청한다. 계약 시 실제 남는 비축만큼 지원 수레를 보내며, 도착해야 재고가 된다. 이후 수확의 12% 조공과 기존 보호자의 방어 규칙을 적용한다. 같은 보호자의 중복 제안은 함께 정리한다.
- **자급과 주택 우선:** 새로운 자동 물물교환을 멈추고 식량과 주거에 집중한다. 새 시작에서 외부 길을 자동으로 열지 않는다. 이미 시작한 운송·개척과 기존 조공 계약은 유지한다. 겨울의 생산 감소를 비축으로 감당한다.

주민의 작업·운반·건설은 계속 자동이다. 첫 겨울의 원인 기록은 세계의 다른 이야기 수가 많아져도 보존한다. 선택 뒤 30일과 첫 겨울이 끝난 시점에 실제 식량 일수·주민·주택·수입·지원·조공을 비교한다. 다른 사건과 계절의 영향도 함께 포함하므로 모든 차이를 선택 하나의 효과라고 단정하지 않는다. 전체 경로를 서로 다른 세계에서 비교하는 검증은 별도로 수행한다.

## 실제 외교와 기존 문제 수정

가까운 다른 마을을 누르면 곡물 교환과 보호 요청의 현재 조건을 볼 수 있다. 정찰 대상도 선택한 상대를 따른다. 통행 위험·재고 부족·목재 부족·개척 중인 상태를 구분해 표시한다. 물자는 출발 때 차감하고 도착 때 지급하는 기존 회계를 사용한다.

‘내가 결정’에서는 경작권 요구와 보호 제안을 자동 거절하지 않는다. 답변할 사건이 오면 UI가 시간을 멈추고 요구 수락·거절을 기다린다. 경작권 양도는 상대의 석재 12를 실제로 받고 생산 기반을 넘긴다. 배속·재생·다음 사건도 답변을 건너뛰지 않는다. 다시 AI에 맡기면 자동 판단을 재개한다.

교역 방침은 목재 수출 작업을 우선하도록 실제 작업 배분을 바꿨다. 우리 마을에 같은 빈 최후통첩을 반복하지 않도록, 보급 여력이 너무 부족하면 압박을 멈추고 재요구 대기 기간을 둔다. 주변 세력의 경제와 전쟁 전체를 임의 일정에 맞춰 생성하지 않는다.

## 검증과 저장

- `tests/winter.cjs`: 세 경로의 실제 자원·주거 차이, 수송 전 지급 없음, 교환 물자 보존, 승인 목재 상한, 지원과 조공, 수동 답변, 30일 비교, 첫 봄, 저장 재현성, 관찰의 RNG·상태 불변.
- `tests/winter-ui.cjs`: 모바일의 세 선택, 다른 마을에서 보호 요청, 실제 지원·조공과 첫 봄의 비교, 수동 외교 때 시간 정지·응답, 정착지 변화.
- `tests/valley-ui.cjs`: PC·390px·320px·가로 화면의 정보량과 조작, 기존 지도·정책·저장·시간 진행. 기본 조작 UI의 사각형 면적 합계는 25% 미만으로 제한한다. 이름표와 사용자가 연 큰 창은 이 면적에 포함하지 않는다.
- 기존 계곡·세력·지형·주민 활동·지도 갱신·10개 세계 회귀 검사를 함께 유지한다.

같은 기본 세계에서 시작해 각 방침을 고르고 180일 진행한 검증에서는, 자급이 주택 1채·외부 연결 없음, 교환이 곡물 수입과 주택 0채, 보호가 지원 72와 주택 2채·조공 납부로 달랐다. 인구는 이 기간 세 경로 모두 12명이었다. 인구 증가를 보상으로 즉시 만들지 않으며 실제 출생·이주 조건이 필요하다. 재미 자체는 플레이 관찰과 추가 피드백으로 평가해야 한다.

저장 키는 기존 `everworld_valley_v2`를 유지한다. 기존 저장에는 현재 시점부터의 겨울 관찰 기준을 한 번만 추가하고 재고·인구·건설·이전 기록을 유지한다. 이전 시기의 선택이나 겨울 결과를 만들어 넣지 않는다. 기존 관찰 전용·직접 조작 모드도 보존한다.
