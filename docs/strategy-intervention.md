# 스스로 살아가는 마을에 전략과 전술로 개입하기

방향 수정: 2026-11-01. 사용자의 최신 지시를 반영한 기획이며, 아래 신규 전술을 구현했다는 뜻은 아니다.

## 플레이어의 역할

플레이어는 기존 세력들 사이에 생긴 작은 마을의 관리자다. 마을과 이웃은 자동으로 살아간다. 플레이어는 **무엇을 우선하고, 누구와 손잡고, 어느 위험을 감수할지** 결정한다.

핵심 흐름은 **자동 생활 → 지도에서 변화 확인 → 필요한 전략·전술 선택 → 주민과 지도자가 실행 → 실제 결과 관찰**이다. 건물·주민 카드는 그 선택의 근거를 알아보는 창이다. 카드를 하나씩 돌며 주민에게 매번 일을 시키지 않아도 된다.

| 마을이 자동으로 할 일 | 플레이어가 결정할 일 |
|---|---|
| 집·밭·작업장이 필요하다는 판단, 적절한 위치 선정, 공사 순서와 재료 운반 | 먹거리 확보·주거 확장·무역 중 현재 무엇을 우선할지 |
| 주민의 일 배정, 작업 장소 이동, 수확·운반, 집 배정 | 노동과 자원을 어디에 더 집중하고 어디서 줄일지 |
| 승인한 조건 안의 반복 거래와 수레 운행 | 거래 상대, 내줄 물자의 한도, 지킬 비축량, 위험 허용 범위 |
| 부대 편성과 이동·전투 실행 | 방어할 대상, 투입할 사람과 물자의 상한, 철수 조건 |
| 다른 마을의 독자적인 생산·거래·외교·흥망 | 우리 마을의 협정·종속·독립과 대응 방향 |

시저에서는 건물과 사람을 통해 원인을 읽는 방식을 참고한다. 배치·도로·개별 작업을 플레이어의 반복 숙제로 가져오지 않는다. 이전 주민 카드 기획은 보조 관찰 기능으로 유지하되 전략적 선택보다 우선하는 필수 플레이로 두지 않는다.

## 전략: 평소에 유지되는 방향

전략은 조건이 바뀌거나 플레이어가 바꿀 때까지 주민의 자동 판단에 쓰인다. 무엇이든 동시에 잘하는 선택을 만들지 않는다.

| 방향의 예 | 마을이 자동으로 할 일 | 얻으려는 것 | 감수할 것 |
|---|---|---|---|
| 겨울 먹거리부터 | 식량 확보와 비축을 우선, 남는 재료·일손으로 건설 | 수입이 끊겼을 때 버틸 여유 | 집과 다른 시설의 증가가 늦어질 수 있음 |
| 나무를 팔아 곡물 확보 | 승인한 상대와 한도 안에서 교환, 수레를 반복 운행 | 불리한 농업 조건을 무역으로 보완 | 건설용 나무 감소, 거래 상대·수송에 대한 의존 |
| 강한 이웃의 보호 | 협정 조건대로 조공, 실제 지원·방어 규칙 적용 | 초기 도움과 외부 위협에 대한 보호 | 수확 일부를 보내야 함, 독자적 선택에 제약이 생길 수 있음 |
| 정착 기반부터 | 최소 먹거리 비축을 지키며 주거·시설 확장 우선 | 정착·성장의 기반 | 비축을 크게 쌓는 것보다 당장의 여유가 적을 수 있음 |

현재 게임의 첫겨울에는 자급·목재와 곡물 교환·보호 요청의 실제 경로가 있다. 이를 첫 전략 선택과 결과 비교의 기반으로 삼는다. 주거·식량·교역 우선 정책도 기존 기능을 활용한다. 전략의 세부 권한·지속 조건·향후 외교 제약은 추가 설계가 필요하며 이미 구현된 것처럼 설명하지 않는다.

방향을 바꿔도 이미 보낸 짐이 되돌아오거나 맺은 협정이 사라지지 않는다. 다른 마을도 자기 필요와 협정에 따라 반응한다. 선택 전에는 알려진 비용과 조건을 보여주고, 선택 후에는 실제로 발생한 후속 반응을 연결한다. 버튼마다 같은 자원 보상만 주는 방식보다 생산 기반·의존 상대·위험의 차이가 다음 판단으로 이어지게 한다.

현재 건물 위치는 자동으로 배정하는 고정 상대 좌표에 가깝다. 자동 배치를 개선할 때는 실제 지형·건물 겹침·작업 위치·이동 거리와 맞춰야 한다. 그 판단과 이유를 마을이 처리하게 하고 수동 배치 메뉴를 필수로 만들지 않는다.

## 전술: 눈앞의 사건에 한시적으로 대응

전술은 특정 사건과 연결하고 종료·실패·철수 조건을 둔다. 사건이 끝나면 기존 전략으로 돌아간다. 유닛 하나씩 이동시키는 조작을 요구하지 않는다.

| 실제 발생한 상황 | 선택의 예 | 비용과 대가 | 현장에서 보일 것 |
|---|---|---|---|
| 식량 유입보다 식사가 많아짐 | 일정 기간 먹거리 확보 최우선 | 건설·나무·돌 작업에 쓸 인력 감소 | 자동 배정 변경, 실제 수확·운반·재고 변화 |
| 거래 경로에 확인된 위협 | 호위 / 출발 연기 / 해당 거래 중단 | 호위 인력과 보급, 늦어진 물자, 포기한 교환 | 수레·호위·대기 상태와 실제 도착 여부 |
| 약한 마을에 외부 병력이 접근 | 마을 방어 / 물자를 챙겨 철수 / 지원 요청 | 생산 인력 감소, 운반 가능한 물자 한도, 원조 조건 | 누가 남고 어디로 이동하는지, 피해와 남은 재고 |
| 강한 세력의 요구가 도착 | 조건 수락 / 거절 / 가능한 다른 협상 | 실제 지불·생산 기반·관계 변화 | 협정 상대, 실제 이전된 물자·권리, 후속 반응 |

표의 기간 제한, 수레 호위, 출발 연기, 물자 철수, 조건별 원조는 **신규 제안**이다. 현재 경작권 요구·보호 협정의 실제 응답 기능과 구분한다. 한 번에 모두 추가하지 않는다. 먼저 기존 첫겨울 전략과 수동 외교 선택의 비용·실행·결과 연결을 완성한 뒤, 기록 가능한 전술 하나를 추가한다.

전술의 재미는 강한 능력을 눌러 즉시 해결하는 데 두지 않는다. 예를 들어 호위 인력을 늘리면 마을의 생산 인력이 줄고, 출발을 늦추면 필요한 곡물의 도착도 늦는다. 이 상충관계는 실제 노동·물자 배분으로 처리해야 하며 설명문에만 적지 않는다.

## 선택이 왜 중요한지 보이게

각 제안에는 다음 다섯 가지를 짧게 붙인다.

1. **왜 지금 필요한가:** 실제 사건·수치에서 나온 이유 한 줄.
2. **무엇을 내는가:** 자원, 일손, 조공 등 실제 비용과 상한.
3. **얼마나 유지되는가:** 지속 방침인지, 특정 사건·기간까지인지.
4. **무엇이 불확실한가:** 상대 재고, 이동, 위협 등 실제 조건. 근거 없는 성공률·확정 도착량을 만들지 않는다.
5. **무엇을 보면 되는가:** 수레 도착, 비축, 공사 지연, 실제 손실처럼 결과가 드러나는 대상.

선택 후에는 지시 번호와 관련 사건·수레·협정·작업 배정을 연결한다. 같은 세계의 실행 전후 재고·인력·건물·거래·납부 기록을 보여준다. 계절이나 다른 사건의 영향도 함께 일어나므로 전체 변화를 명령 하나의 효과라고 단정하지 않는다. 실행하지 않은 선택의 가짜 결과 그래프도 만들지 않는다.

## 개입하지 않을 때

마을과 다른 세력은 계속 판단하고 움직인다. 필수 클릭을 기다리느라 생산·운반·건설이 멈추는 구조를 만들지 않는다. 플레이어는 대응을 맡길 범위를 정할 수 있어야 한다.

- 승인한 교역·비축·위험 한도 안의 일상적인 판단은 자동 실행한다.
- 수락 권한을 주지 않은 보호·영토 양도 등 큰 결정은 자동 체결하지 않는다. 거절·보류 등 기본 대응과 상대가 제시한 실제 기한을 표시한다. 실제 게임에 기한 규칙이 없으면 임의 카운트다운을 붙이지 않는다.
- 기존 `내가 결정`의 외교 일시정지는 유지하고 `AI에 맡기기`와 구분한다. 새 자동 대응 규칙을 도입할 때도 저장된 수동 설정을 덮어쓰지 않는다.
- 부재 중에도 모든 사고를 피할 수 있다고 보장하지 않는다. 돌아오면 발생한 실제 변화와 자동 대응을 짧게 보여준다.

이는 실행 중인 자동 시뮬레이션에 대한 설계다. 브라우저를 닫은 시간의 계산·서버 상시 진행 기능이 이미 있다는 뜻은 아니다. 오프라인 진행은 별도로 구현·검증해야 한다.

## 화면의 중심

기본 화면은 지도와 현재 방향 한 줄이다. 답변할 사건이 있을 때만 작은 진입점을 보여준다. 전략 창은 필요할 때 열며 현재 상황에서 의미 있는 선택을 우선한다. 플레이어가 닫으면 전체 지도를 다시 본다.

건물·주민·먹거리 카드는 기존처럼 눌러 살펴볼 수 있다. 주민에게 작업 버튼을 추가하지 않는다. 예를 들어 밭을 눌러 수확보다 운반이 늦다는 실제 상황을 확인한 다음, 마을 전체의 우선순위나 물자 확보 방식을 바꾼다. 세부 관찰은 선택의 이해를 돕는 선택적 깊이다.

첫 5분의 목표는 다음과 같다.

1. 작은 마을과 이미 움직이는 이웃을 본다. 건물과 작업 위치는 마을이 정한다.
2. 현재 문제 하나와 실제 비용·조건이 다른 선택 2~3개를 본다.
3. 방향을 정하거나 판단을 AI에 맡긴다.
4. 주민의 배정, 수레 출발, 공사 등 실제 실행을 지도에서 본다.
5. 시간이 지난 뒤 결과를 보고 같은 방향을 유지할지 바꿀지 판단한다.

## 개발 우선순위

1. 기존 첫겨울·정책·교역·보호·수동 외교를 하나의 전략 진입점과 실제 비용·이유·결과로 연결한다.
2. 자동 배치·자동 배정의 판단 이유, 현재 적용 중인 방침, 비용 한도와 실행 상태를 드러낸다.
3. 기존 지원 경로와 양립하는 전술 하나를 정하고, 실제 자원·인력 보존과 종료 후 전략 복귀를 구현한다.
4. 건물·주민 관찰을 보강한다. 개인 카드는 실제 주민 번호·집·일터가 준비된 범위만 제공한다. 세계 전체 개인 모델의 완성을 첫 전략 플레이의 선행 조건으로 두지 않는다.

검증은 같은 초기 세계에서 다른 방향이 실제 자원·주거·교역·의존·피해로 달라지는지, 관찰만 해도 진행되는지, 비용 한도·수동 권한을 지키는지, 전술 종료 후 원래 방침이 복원되는지에 둔다. 지도·카드 선택이 난수·경제를 바꾸면 안 된다. 재미는 사용자가 다음 결과를 기다리고 방향을 다시 결정하는지 실제 플레이로 확인한다.
