# 살아있는 왕국 v2.2 — 농경·세대교체·자율 전업 검증

검증일: 2026-10-15
기준: public GitHub main/index.html. 아래 결과는 규칙 엔진 자동 실행 시뮬레이션이며 실제 중세 역사 통계에 근거한 교정치가 아니다.

## 이번 구현

### 밭 단위 농사
- 가상 왕국력 1840년 1월 1일부터 시작. 최초 밭 8필지.
- 봄에 농부가 씨앗용 곡물을 실제 재고에서 차감하여 파종.
- 이후 일간 계절·날씨·흉작 상태·관리에 따라 성장도 누적.
- 성장 완료 후 농부가 실제로 수확해야 곡물 재고 증가. 농부가 없으면 씨앗 파종이나 수확이 되지 않는다.
- 밭의 지력은 수확 시 감소하고 휴경 중 회복. 농업 기술·수로·농부의 관리가 수확량에 반영.
- 인구가 늘고 목재와 도구가 확보되면 주민들이 새 밭을 개간할 수 있음 (최대 14필지).
- 농경지 상태를 지도 색상으로 표시: 휴경·성장·수확 준비·실패.

### 가족과 일생
- 주민에게 가족·배우자·부모 식별자가 생김. 기존 주민들이 가구를 형성.
- 1840년 이후 혼인과 출산이 발생. 아이는 즉시 성인 노동자로 취급되지 않고 15세부터 기초 노동을 배우기 시작.
- 가족이 마련해 둔 개인 식량이 있으면 어린이에게 우선 나눠줄 수 있음.
- 주민이 사망하면 살아 있는 배우자·자녀에게 소지금과 개인 식량을 넘길 수 있음.
- 기존의 나이·숙련도 성장과 60세 이후 체력 감소 규칙을 유지.

### 자율적 직업 변화
- 인구 대비 농부가 부족하거나 식량이 위험하면 다른 생업의 주민이 농사 수습 교육을 시작.
- 수습 기간에는 생산이 줄어들며 교육 완료 후 전업.
- 목축 인력이 사라지거나 목수가 부족할 때도 상황에 맞춰 재교육 가능.
- 마을이 잉여 농산물을 충분히 보유하고 물물교환이 열리면 일부 농부가 상인으로 전환.
- 굶주림 위기에는 일부 비농업 직업도 임시로 구근과 나물을 채집. 산림 자원을 실제로 소모.

### 성장 한계
- 집은 처음부터 완전히 열려 있지 않으며 목재·돌·도구와 노동으로 증축 (현재 최대 12동).
- 개간도 자원과 인력이 필요하며, 무한히 밭을 만들지는 못함.
- 비축 식량이 있어야 아이·이주민을 수용하고 전문직도 유지할 수 있음.

## 다중 세계 자동 검증

서로 다른 시드 12개를 각 최대 20게임년 동안 플레이어 개입 없이 자동 실행. 마을이 멸망하면 즉시 중지.

- 20년 존속: **6개**
- 20년 이전 멸망: **6개**
- 세계당 출생 평균: 약 **14.8명** (중도 멸망한 세계도 포함)
- 세계당 수습 전업 완료 평균: 약 **2.4회**
- 필요 시 비농업 인력이 임시 채집으로 확보한 식량 평균: 약 **1,191단위**
- 8개 식량 품목 합계와 식량 총합 불일치: 시험한 세계에서 **0건**
- 시험 중 JavaScript 엔진 예외: 이번 테스트에서 발견되지 않음

20년을 버틴 세계에서도 어린이가 15세에 도달해 노동 역할로 전환됨. 일부 세계는 왕국력이 1860년에 도달할 때까지 가문과 농업 인력을 계승.

### 모든 농부를 초기에 없애는 대조 시험
시드 5개에서 최초 농부 4명의 직업을 노동자로 바꾸고, 3년간 자동 진행.
- 농부 재교육과 전업이 **5개 세계 모두**에서 일어남.
- 실험 5개 세계 모두 3년 시점에 농부가 다시 배치되어 마을이 존속함.
- 이는 해당 테스트에서 관측한 결과이지 어떤 농업 붕괴에서도 항상 생존한다는 보장은 아님.

## 발견된 한계와 다음 우선 개선

1. **기근 멸망률이 높다.** 20년 동안 12개 중 6개 멸망은 역사적인 기근의 실제 확률을 검증한 수치가 아님. 한 번의 흉작이 집단 사망으로 과도하게 전파되는지 더 분석해야 한다.
2. **수확량·토지 생산성 단위는 게임용 추상치다.** 토지 면적, 종자 종류, 비옥도 측정치와 실제 농업 기록을 검증한 모형이 아님.
3. **기술·직업 전환은 제한된 규칙 기반이다.** NPC의 다년 계획, 재교육의 실제 가구 부담, 노동 계약과 취업 경쟁은 아직 추상화됨.
4. **가구 경제는 초기 버전이다.** 배우자·자녀 관계와 일부 식량 지원·상속은 있지만, 가족 공동의 재산·농지 소유·개별 수입 지출은 완성되지 않았다.
5. **최대 건물·밭 수 제한이 있다.** 도시의 물리적 확장을 무한히 시뮬레이션하는 게임이 아니다.
6. **게임은 브라우저에서만 자동 진행한다.** 전체 사용자를 위한 상시 서버 시뮬레이션이 아니다.
