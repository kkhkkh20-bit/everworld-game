# 숲과 강의 풍경 개편

듬성듬성 놓인 나무 사이의 넓은 잔디를, 마을과 길을 둘러싸는 울창한 숲으로 바꿨다. 기존 CC0 KayKit 수목 두 종류를 재사용하고 크기·회전·색을 섞었다. 기본 세계에서는 약 17,000그루가 표시된다. 지형의 완만한 밀도 변화와 위치 흔들림을 사용하며, 마을·경작지·작업 장소·길·물가는 비운다. 새 길이 개통되면 해당 길을 덮던 나무만 표시에서 제거한다.

본류의 평균 전체 폭은 기본 세계에서 약 25.9 지도 단위다. 이전 강은 7.6이었다. 네 곳의 외곽 나루에서 이어지는 지류를 추가했다. 마을과 시설·경작지의 여유 공간을 보고 강줄기와 폭을 조정하며, 같은 마을에 속한 건물과 밭 사이를 강이 억지로 관통하지 않도록 한쪽 강변으로 묶는다.

물은 깊은 중심부·청록색 얕은 부분·모래빛 강둑으로 나누고 작은 물결 선과 강변 바위를 더했다. 실제 지면을 강 아래로 내려 물과 잔디가 겹치지 않게 했다. 기존 지도 경계의 일정한 산벽 대신 크기와 간격이 다른 산봉우리 무리를 배치했다.

기존 길이 본류나 지류를 통과하는 모든 구간을 계산해, 강둑 양쪽에 닿는 길이의 다리를 놓는다. 물에 잠긴 구간에는 흙길을 그리지 않는다. 수레는 동일한 경로 위에서 다리 높이를 따라 표시한다. 세력 지도의 축소 지도도 같은 강줄기와 강폭을 사용한다.

장식 지형은 `js/valley-landscape.mjs`에서 계산하며 시뮬레이션의 난수·인구·자원·관계·교역로를 변경하지 않는다. 나무를 더 표시한다고 목재 재고가 늘지는 않는다. 기존 원정은 집계 이동 모델이며 이 작업에서 해군·하천 항해·다리 건설 비용 체계를 추가하지 않았다.

수목은 공간별 인스턴스 묶음으로 그린다. 일시정지 후 카메라가 멈추면 기존처럼 그리기를 쉰다. FPS 개선을 측정했다고 주장하지 않는다.

검증:

- `node tests/landscape.mjs`: 두 씨앗의 숲 밀도, 넓어진 본류와 다섯 물줄기, 모든 수로 횡단 구간의 다리, 건물과 밭이 물에 잠기지 않음, 표시 계산의 상태 불변, 900일 진행한 저장의 건물 위치.
- `node tests/valley-ui.cjs`: PC·모바일·가로 화면의 실제 에셋·숲·강·다리, 지도 조작과 관찰의 상태 불변, 정지 화면의 그리기 중단, 창·정책·저장 복원.
- 기존 경제·세력·주민 활동·지도 갱신·10개 세계 회귀 검사를 유지한다.
