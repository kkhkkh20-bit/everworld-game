# 새벽숲 — 작은 마을의 시작

사용자가 요청한 새 방향: 큰 세력들 사이에서 내 마을을 건설하고, 새 동료를 받아들여 독립된 교역촌으로 성장한다. 기존의 문명 관찰 우선 방침보다 이번 요청을 우선했다.

- 홈페이지 진입은 `frontier.html`로 연결한다. 예전 세계는 `index.html?classic=1`에서 계속 실행할 수 있다. 기존 저장 키와 시뮬레이션은 유지한다.
- 새 시나리오는 별도 저장 키 `everworld_frontier_v1`을 쓴다. 브라우저 로컬 저장이며 새 마을 시작 전 확인한다.
- 첫 집(6일) → 로운 가족 영입(3명, 식량 25) → 대장간(8일) → 도구 판매(목재 12를 금화 24로, 5일 간격) → 교역소(7일) → 협정(금화 40, 독립 선택 후에는 60)의 짧은 첫 장이다.
- 공동 밭과 식량 중심 작업은 식량을 확보한다. 긴 비는 23일째에 식량 35를 소모한다. 32일째 북부 사절은 목재 30의 조공 또는 독립(협정 교섭금 +20)을 제안한다.
- 집·시설은 자재를 실제 차감하고 공사 기간 뒤 지도에 추가한다. 협정 수입도 재고에 반영한다. 이야기는 해당 사건의 실제 상태 변경에서 기록한다.
- 첫 협정 이후 계속 건설·교역할 수 있다. 현재는 세대교체·영토 확장·전투를 새 시나리오에 구현하지 않았다. 주민의 지도 이동은 연출이고 자원은 일 단위 정착지 모델이다. 주변 두 세력은 이 첫 장의 교섭 상대이며 완전한 국가 시뮬레이션은 아니다.
- 라이선스: Kenney CC0 지도/주민 타일, Game-icons의 Lorc/Delapouite CC BY 3.0 아이콘. `THIRD_PARTY_ASSETS.md`와 게임 내 도움말에 출처를 표시한다.

## 로컬 실행과 검증

저장소 루트에서 `python3 -m http.server 8020 --bind 127.0.0.1` 실행.

- `node tests/frontier.cjs`: 건설 비용·기간, 초대 조건·중복, 교역 간격·협정 수입, 독립 선택, 재초대, 1000일 재고 검증.
- `node tests/frontier-ui.cjs`: 위 서버 필요. 제공된 Playwright와 `/usr/bin/chromium` 사용. 1440/390/320px에서 실제 버튼으로 집→영입→대장간→도구 판매→협정→저장/복원을 검증한다. 이전 게임의 실제 HTTP 초기화도 확인한다.
- `node tests/simulate.mjs`: 기존 시뮬레이션 회귀 검사.

기존 HTML 주입형 UI 테스트는 단일 HTML을 모든 경로에 응답하는 자체 서버를 쓰므로 새 외부 진입 스크립트/정적 파일 경로를 제공하지 않는다. 이전 게임 브라우저 회귀 검증에는 실제 정적 서버의 `index.html?classic=1`을 사용한다. 홈페이지 변경을 수용하도록 기존 테스트 서버를 개선하는 작업은 별도 범위다.

## 전체 화면 플레이 UI

지도 캔버스가 뷰포트 전체를 채운다. 별도의 페이지 스크롤이나 고정 사이드바 없이 하단 건설·동료·외교·기록·설정 버튼으로 게임 안의 창을 연다. 닫기 버튼 또는 Escape로 돌아가며, 창을 열어도 시간은 계속 진행한다. 일시정지는 하단 시간 조작에 있다. 건설 시작 후에는 창을 닫아 공사 중인 지도를 보여준다.

지도는 마우스/터치 드래그, 휠/두 손가락 확대, 확대·축소·중심 복귀 버튼, 지도 포커스 후 방향키와 +/-로 조작한다. 건물 선택 좌표는 카메라 변환을 역산한다. 설정에는 작업 배분·전체화면·새 시작·이전 게임·출처가 있다. 1440×1000, 390×844, 320×844에서 전체 진행과 창 조작을 확인하고 844×390 가로 화면도 확인했다.

단일 파일 배포본: `python3 scripts/package-frontier.py /tmp/saebyeok-forest.html`. CSS·JS·PNG·SVG를 모두 포함하므로 외부 그래픽/스크립트를 요청하지 않는다. 빌드 산출물은 저장소 밖에 둔다. 관리형 Chromium은 `file://` 탐색을 정책상 차단하여, 생성한 HTML을 로컬 HTTP 응답으로 제공해 독립 실행과 외부 요청 없음을 검증했다. 공개 GitHub Pages 배포는 별도로 필요하다.
