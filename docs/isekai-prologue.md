# 새벽숲: 이세계의 첫 집

사용자가 승인한 새 방향: 홀로 이세계에 떨어진 주인공을 직접 조작하고, 음식을 나눠 동료를 맞이하고, 일을 맡기며 첫 집을 함께 짓는다. 최신 사용자 지시에 따라 기존 관찰 전용 기본 방향보다 직접 조작을 우선한다.

## 실제 플레이

1. WASD·방향키·땅 터치로 주인공 이동. 자원 터치는 이동→채집→운반을 한 번 수행한다. E는 선택한 대상/가까운 대상 작업. 모바일 이동 버튼도 제공한다.
2. 목재 3개를 직접 가져온 뒤 건설에서 모닥불 터를 정한다. 창고→현장 운반 후 실제 작업 시간이 쌓여야 불이 완성된다.
3. 불빛을 따라 미라가 온다. 열매 2개를 모아 창고에 보관하고, 가까이 다가가 나눠 동료로 맞이한다.
4. 동료에게 휴식·벌목·열매·석재·건설 중 하나를 맡긴다. 이동, 작업, 운반, 재료 부족, 공사 대기, 휴식 상태를 지도와 동료 창에서 확인한다.
5. 목재 12·석재 4를 운반하고 12초의 건설 작업을 수행해 첫 집을 완성한다. 혼자였던 숲에 둘의 집이 생겼다는 장면을 보여준다.
6. 집을 본 로운을 영입하면 작업장(한 번에 채집 +1), 강을 건너는 다리까지 계속 지을 수 있다.

## 시뮬레이션 계약

- `js/isekai-engine.js`는 DOM 없이 이동·채집·자원·공사를 처리한다. 그리기는 상태를 읽기만 한다. 렌더 프레임 수는 생산량을 결정하지 않는다.
- 자원은 노드에 유한하게 있고 작업 2.4초 뒤 손짐으로 옮겨진다. 창고 도착 때만 보유 자원이 증가한다. 열매는 고갈 후 45초에 일부 재생한다. 이전의 일 단위 자동 생산을 이 모드에서는 사용하지 않는다.
- 건설은 창고에서 가져갈 때 자원을 차감하고 `reserved`에 예약, 현장 도착 때 `delivered`로 이동한다. 여러 건설자의 운반이 중복 자원을 만들지 않는다. 자재가 현장에 모두 도착하기 전에는 건설 진행이 오르지 않는다.
- 하루는 시뮬레이션 120초. 1인당 열매 1개 소비. 현재 식량 부족은 기록과 재고 관리 문제이며 사망/전투/완전한 욕구 시뮬레이션은 없다. 지친 작업자는 창고 곁에서 쉬고 재개한다.
- 저장 키 `everworld_isekai_v1`. 인물 위치·손짐·노드 잔량·공사 예약·일 배정이 함께 저장된다. 기존 교역촌 저장은 `frontier-trade.html`, 문명 관찰은 `index.html?classic=1`에서 유지한다.
- 현재 고정된 첫 숲과 세 명까지의 작은 첫 장이다. 자유 건물 배치·국가 외교·전투·세대교체는 이 새 모드에 구현하지 않았다.

## 검증

- `node tests/isekai.cjs`: 자동 생산 없음, 창고 이전 재고 불변, 손짐 저장 복원, 불 피우기, 근접·식량 초대 조건, 업무 배정·휴식, 실제 공급/공동 건설, 재료 부족, 직접 이동 중단.
- `node tests/isekai-ui.cjs`: 8020 정적 서버에서 1440/390/320px 실제 지도 클릭·WASD·메뉴 버튼으로 첫 집 완성·저장 복원.
- `node tests/frontier.cjs` 및 `node tests/frontier-ui.cjs`: 별도 보존한 교역촌 회귀.
- `node tests/simulate.mjs`, `tests/resident-activity.cjs`, `tests/render-budget.cjs`: 이전 문명 시뮬레이션/지도 회귀. 후자의 HTML fixture는 새 모드 이동 스크립트만 제거해 원래 게임을 검증한다.
- `python3 scripts/package-frontier.py /tmp/saebyeok-forest.html`: 현재 이세계 모드를 단일 HTML로 묶는다.
