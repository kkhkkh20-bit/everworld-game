# 산들계곡 v2 — 지켜볼 이유가 생기는 세계

최신 요청은 주민 개별 조작보다, 각 마을이 필요 때문에 교역하고 공급·경작권 때문에 갈등하는 자율 세계를 관찰하는 것이다. 기존 여섯 마을과 CC0 3D 모델을 유지하고, 경제·외교·전쟁을 하나의 식량·자재·노동 흐름에 연결했다.

## 실제로 달라진 규칙

- 농촌은 곡물에, 숲 마을은 목재에, 성채는 석재에 유리하다. 인구 밀도·계절·지역 기후·경작권·시설 상태가 실제 생산량을 바꾼다. 수확물은 창고로 가져와야 재고가 된다.
- 비축에는 저장 한계와 부패가 있고 주택과 시설에는 유지 자재가 든다. 굶주림과 시설 악화는 생산을 약화시키며, 인구 감소 뒤에는 빈집이 표시된다. 자재 부족이 오래가면 시설이 폐쇄되고 복구 공사에는 자재와 노동이 다시 필요하다.
- 교역은 필요한 물자와 내보낼 수 있는 잉여를 비교한다. 교환 비율은 양쪽의 부족 정도를 반영한다. 재고를 출발 때 예약·차감하고, 양쪽 운송이 도착할 때만 지급한다. 항구를 통과하면 물자의 6%가 실제 통행료로 이전된다. 전쟁으로 길이 위험해지면 우회로를 찾거나 기다린다.
- 물자를 구할 수 없거나 곡물 수입 의존이 큰 세력이 경작권을 요청한다. 소유자에게 비축과 여유가 있으면 석재를 받고 권리를 넘길 수 있다. 거절→최후통첩 뒤에도 군사적 이익·상대 방어·동원 가능한 사람·실제 보급을 감당할 수 있어야 출정한다. 달력만 보고 전쟁을 생성하지 않는다.
- 원정 병력은 생산에서 제외된다. 양측 전사자는 해당 마을 인구에서 차감한다. 보급은 소비되고, 생존 병력과 남은 물자는 실제 귀로를 마쳐야 돌아온다. 전멸하면 남은 보급도 회수하지 못한다. 경작권을 빼앗으면 생산 기반이 실제로 이전된다.
- 보호를 받으면 이후 수확의 12%를 조공으로 보낸다. 보호자에게 여력이 있으면 실제 인구를 동원해 방어를 돕는다. 보호자가 사라지면 조공 관계도 끝난다. 자동 판단은 조공과 생존 여건을 비교하며, 사용자가 개입할 수도 있다.
- 식량·유지 여건이 나빠진 마을에서는 실제 주민이 떠난다. 목적지 도착 전에는 이동 중 인구로 따로 집계한다. 출생·기근 사망·전쟁 사망·유입·유출을 구분한다.

## 시작과 관찰

기존 다섯 마을은 새 규칙으로 먼저 180일간 운영된다. 버들나루는 모촌의 지원을 받는 분촌이 아니라 외곽에 새로 나타난 12명의 정착지다. 초기 식량은 약 9일분이며 외부 길과 보호자는 없다. 정찰은 식량 5와 한 작업조의 10일을 사용한다. 이웃을 발견한 뒤 목재 12·석재 3과 추가 노동으로 첫 숲길을 열어야 교역이 가능하다. 기본 AI가 식량을 마련하고 이를 스스로 판단하므로 관찰만 해도 진행된다.

세계 이야기에는 실제 사건 ID에 연결된 원인·전개·결과가 나온다. 수입 의존, 협상 거절, 보급 지출, 전사자, 경작권 이전과 회복을 같은 이야기에서 따라갈 수 있다. 확인되지 않은 과거를 생성하지 않는다. 지도에는 실제 길·이동 수레·피란·병력·경작지 소유·빈집·폐쇄 시설이 보인다. 사건 따라보기를 켜면 중요한 새 사건의 현장으로 이동하며, 사용자가 직접 지도를 조작하면 따라보기를 멈춘다.

'다음 중요한 변화'는 최대 35일을 실제로 계산하며, 이벤트를 만들어내지 않는다. 진행은 중단할 수 있다. 표시와 카메라는 RNG나 경제를 바꾸지 않는다. 일시정지해 카메라가 멈추면 다시 그리기를 멈추는 기존 구조를 유지한다.

## 검증한 것과 한계

- `node tests/valley.cjs`: 고립된 시작과 실제 정찰·연결, 마을 간 의존과 쇠퇴, 인구 보존, 저장 재현성, 양방향 거래·통행료 보존, 협상 합의와 거절→최후통첩→보급 가능한 전쟁, 전사자, 실제 보호 병력, 풍부한 조건에서 자동 전쟁 없음, 곡창의 공급 충격이 수입 마을에 미치는 영향.
- `node tests/valley-ui.cjs`: 1440/390/320px 실제 3D 에셋, 원인별 이야기, 외교·정책, 자율 변화, 저장 복원, 다음 사건 진행, 카메라 상태 불변, 화면 오류와 스크롤 없음.
- 여섯 씨앗을 각각 900일 추가 진행해 인구 회계와 재고를 확인했다. 시험 당시 전쟁은 4~7회였고, 씨앗에 따라 인구·이주·피해가 달랐다. 재미 자체는 실제 사용자 관찰이 필요하다.
- 전투는 여섯 정착지의 경작권을 두고 벌어지는 집계 원정 모델이다. 상세 전술·개별 병사 생애·모든 외교 제도·정밀한 정보 전달 시간은 구현하지 않았다. 경제와 군사 수치는 역사적 실증 모델이 아니다. 마을당 시설 상한은 24개이며 지도 인물은 작업조/병력의 표시다.

## 저장과 이전 버전

새 저장 키는 `everworld_valley_v2`. 기존 `everworld_valley_v1`은 변경하지 않는다. 설정의 `valley-legacy.html`에서 이전 계곡을 계속 플레이할 수 있다. 이세계·교역촌·원래 문명 관찰 모드와 저장도 그대로 유지한다.

정적 서버 실행: 저장소에서 `python3 -m http.server 8020 --bind 127.0.0.1` 후 `frontier.html` 접속. 배포는 기존 GitHub Pages 워크플로를 사용한다. JS와 CSS에 버전 쿼리를 붙여 이전 브라우저 캐시가 새 화면과 섞이지 않게 했다.
