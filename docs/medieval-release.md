# 중세 관찰 플레이 릴리스 — 2026-10-22

지도에서 주민의 생업과 마을 성장을 보고, 한 인물의 실제 후손을 따라가는 관찰 플레이를 연결했다. 기존 저장과 사망 기록을 보존한다.

- Kenney CC0 Tiny Farm 작업복·농작물·가축·곡물창고를 Tiny Town 주택과 Tiny Dungeon 경비병에 맞춰 사용한다. 주택 지붕, 마을 회관, 깃발, 시설, 계절을 구분하고 깊이에 따라 그린다. 모든 에셋은 HTML 안에 포함된다.
- 주민 → **삶 따라가기** → 자녀 성장·독립 살림·실제 3대·지도자 배출의 기록을 남긴다. 후계자는 실제 부모 ID로 찾고, 죽은 인물을 부활시키지 않는다.
- 지도 소식 → **현장 보기**로 당사자나 마을에 이동한다. **다음 사건까지**는 실제 사건이 나오면 정지하고, 없으면 최대 달력 1년에서 멈춘다.
- 27개에서 막히던 농지를 실제 영토의 비옥도·재료·노동 비용 안에서 최대 96개까지 확장한다. 남쪽 새 농지에는 다리와 연결 동선이 있다. 주택은 80채까지 유효 크기의 부지를 확보한다.
- 교역은 다음 수확까지 필요한 식량을 먼저 비축한다. 돈·식량·주민을 검사에 임의로 보충하지 않았다.
- 모든 건너뛰기는 화면에 제어를 돌려주며 중단할 수 있다. 건너뛰기 도중 반복 저장을 줄이고 완료·중단 시 저장한다. 가로 휴대폰의 주민 카드에는 네 행동 버튼을 한 줄로 배치했다.

## 실제 실행 결과

100년 장기 실행은 진행 중이다. 아래 장기 행은 마지막 완료된 연도까지의 중간 결과이며, 100년 통과를 의미하지 않는다.

| 버전 | 시드 | 실행 일수 | 마지막 본촌 인구 | 누적 굶주림 사망 | 생존 마을 | 누적 전투 |
|---|---:|---:|---:|---:|---:|---:|
| published baseline | 1840 | 36,500 | 6 | 304 | 32 | 361 |
| medieval release | 7 | 10,950 | 104 | 0 | 28 | 49 |
| medieval release | 1 | 10,950 | 79 | 0 | 32 | 31 |
| medieval release | 1840 | 24,455 | 321 | 0 | 30 | 429 |

수치는 [원자료 요약](medieval-release-audit.json)에 있다. 30년은 10,950일, 100년은 36,500일의 연속 일일 계산이다. UI의 연 단위 건너뛰기는 별도로 윤일을 반영하며, 1840년의 1년은 366일로 검사했다. 장기 실행 중 성능 수정 시 일일 경계의 실제 저장을 이어받았고 첫 체크포인트의 로드 전후 전체 상태가 같음을 확인했다. 기존 기준 버전은 100년 동안 두 차례 대규모 기근을 겪었다. 수정 버전의 결과가 모든 시드에서 기근이나 멸망이 없음을 보장하지는 않는다.

## 검증

- `node tests/simulate.mjs`: 10개 시드, 결정적 재실행, 발전·교육·교역 재고 보존·개척·전투·영토 변화.
- `node tests/cache-parity.cjs`: 시드 1840의 1,095일과 시드 7의 730일에서 캐시/기존 정렬과 전체 상태·난수 일치, 같은 날 가구 이전 후 채무 조회.
- `node tests/famine.cjs`: 손실률, 회복, 개인 식사, 종자 보존, 실제 교역, 확장 농지 비용, 수확 전 수출 제한, 실제 멸망 기록.
- `node tests/medieval-release.cjs`: 실제 후손 계승, 거짓 3대 기록 방지, 저장/재접속, 사건 위치, 실제 건설 사건 정지, 80개 집터, 남쪽 농지 다리, 320px·가로·데스크톱 카드.
- `node tests/map-surface.cjs`, `node tests/time-controls.cjs`: 실제 지도 입력, 모든 마을 전환, 30일 완료, 100년 중단, 두 손가락 확대, 6개 화면 크기의 고배속 누르기 유지, 1/6/24배속 가상 시계, 366일 완료.
- `node tests/society.cjs`: 독립 가구·재산 보존·혼인 제한·분가·세력·선거, 자연 900일 출생과 세력 형성.
- `node tests/survivor-motion.cjs`: 1871년 생존자 3명의 기존 저장에서 재설정 없는 이동, 정지, 실제 멸망, 3배 픽셀 화면.
- 실제 321명·29개 마을의 장기 저장을 Chromium 휴대폰 390×844·3배 화면에 불러와 이동, 가문 카드, 문명 지도, 가로 화면 네 행동의 터치 위치와 브라우저 오류 없음을 확인했다.

별도 90일씩 성숙한 저장에서 전체 상태를 매일 비교했다. 176명 농업 계약/밭 선택 계산은 약 58.5초 → 17.4초, 321명 채무 조회 계산은 약 35.2초 → 13.9초였다. 이 측정은 해당 개발 환경의 결과이며 기기별 배속 보장이 아니다. 장기 시간 건너뛰기는 여전히 계산 시간이 필요하다.

## 범위

현재는 지도 중심 관찰과 기존 수련·정책 개입을 연결한 버전이다. 완전한 장수제 RPG나 개인 직접 조작 시스템은 아니다. 본촌 주민은 개별 가족·가문으로 계산하지만 다른 마을은 인구·시설 단위 모델과 대표 주민 표현을 유지한다. 멸망한 기존 저장의 인물을 임의로 되살리지 않는다. 새 출발은 지도 설정의 **64명 시작**에서 선택할 수 있다.
