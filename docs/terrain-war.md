# 지형과 성채 전쟁

새 세계에는 강·산지·숲·해안·사막의 초기 공동체가 생긴다. 강은 다리와 양안 취락, 산지는 계단식 취락, 해안은 항구, 사막은 오아시스를 중심으로 배치한다. 지형별 식량·목재·석재 생산량과 방어력이 다르며 강과 사막은 자재를 써 관개 시설을 발전시킨다. 기존 저장은 지형과 마을 좌표를 유지한다.

마을의 `성벽 · 군대` 카드에서 목책→석성→요새, 병영, 병사 모집, 훈련, 보수를 명령한다. 건설과 훈련에는 실제 식량·목재·석재 및 시간이 필요하다. 여유가 생긴 공동체도 스스로 건설한다. 모집은 기존 주민 안에서 이루어지며 원정 병력은 생산에서 제외된다.

전쟁은 진군→공성→돌파전→귀환 단계로 진행한다. 성벽 내구도, 지형 방어, 숙련, 병영의 공성 장비가 영향을 준다. 보급이 부족하거나 제한 기간 안에 성벽을 돌파하지 못하면 철수한다. 승리 후 충분한 병력이 남으면 마을을 점령하고 깃발과 영토의 지배 세력이 바뀐다. 주민의 신원·가족·건물은 유지된다. 점령지 식량난이 이어지면 충성도가 떨어져 독립할 수 있다.

전투는 전략 시뮬레이션이다. 개별 병사를 직접 이동시키는 전술 조작은 제공하지 않는다. 이웃 마을의 주민 그림은 인구·직업 통계를 표현하는 시각화이며 원래 마을처럼 전원 개별 가계 시뮬레이션을 하는 것은 아니다. 성벽은 공성 계산에 적용되며 보행 충돌 지형은 아니다.

검증: `node tests/terrain-war.cjs`로 지형, 실제 자원 비용, 건설 기간, 공성·점령·철수·귀환, 원래 마을 점령 시 인물 보존, 저장 복원을 검사한다. `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/terrain-war-ui.cjs`로 다섯 마을 배치, 모바일 터치 명령, 공성 표시와 브라우저 저장 복원을 검사한다. `LEGACY_SAVE=... node tests/terrain-war.cjs`로 기존 저장의 자원·인물·마을 위치 보존을 추가 검사한다.

10년씩 3개 시드(1840, 7, 1), 총 10,950일 검증 결과: 원래 마을 인구는 102/103/94명, 굶주림 사망은 모두 0명, 전투 0/3/9회, 점령 상태인 마을 0/2/4곳이었다. 모든 세계에 성벽과 병영이 자율 건설됐고, 자원 원장과 음수·비정상 수치를 매월 검사했다. 전투·점령 수를 강제로 맞추지 않는다. 상세 연간 결과는 terrain-war-audit.json에 있다.
