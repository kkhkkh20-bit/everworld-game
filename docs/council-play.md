# 마을 회의: 선택 → 실행 → 결산

이 변경은 기존 자급·교환·보호의 경제를 실제 게임의 전면으로 가져온다. 첫 의사결정이 생활 메뉴의 접힌 항목 안에 묻혀 있던 문제와, 선택 뒤 무엇을 기다려야 하는지 불명확했던 문제를 다룬다. 재미가 검증됐다는 주장은 아니며, 사용자가 선택의 대가와 실제 결과를 보고 다음 방향을 다시 결정할 수 있게 하는 첫 개선이다.

## 플레이

화면 아래 **마을 회의** 또는 지도 위 회의 알림을 연다. 첫 겨울을 독립으로 버틸지, 건축 목재를 곡물과 교환할지, 수확 일부를 바치며 이웃의 보호를 받을지 선택한다. 교환 상대·회당 비용·정찰 비용·이동 시간은 현재 세계의 견적이다. 원조와 교역물은 실제 도착 전까지 보상으로 지급하지 않는다. 물 운반과 먹거리 세부 방침은 기존 생활 화면으로 이어진다.

**결정의 다음 변화까지 관찰**을 누르면 우리 마을을 보면서 최대 30일을 진행한다. 실제 건설·마일스톤·외교·위기·물자 도착 또는 관찰 기한에서 멈춰 진행 보고로 돌아온다. 진행 도중 상단 일시정지로 중단할 수 있다. 직접 답해야 하는 외교 요구가 생기면 기존 답변 화면을 우선한다. 반복 관찰을 통해 30일 결산에 도달하며, 이후에도 방침은 플레이어가 바꿀 때까지 유지된다.

보고에는 주민·식량 비축·집·목재의 전후 수치, 실제 도착한 곡물·지원·납부 조공과 관련 사건이 나온다. 다른 사건과 계절도 포함된 결과이며 전부를 명령 하나의 효과라고 주장하지 않는다. 관찰 도중에는 현재 실행 상태를 표시하고, 30일 결산은 해당 시점에 고정한다. 기록이 없는 과거 사건은 만들지 않는다.

첫 집, 농장과 식량 20일분, 첫 외부 물자 도착의 세 목표는 현재 건물·비축·수입 장부에서 읽는다. 자동으로 성장하는 실제 마을을 확인하기 위한 표식이며 별도의 자원 보상이나 해금 규칙은 없다. 첫 외부 물자는 교역과 지원을 구분해 표시한다.

## 구현과 호환성

`js/valley-council.mjs`는 기존 엔진 명령과 30일 비교 기록을 사용한다. 회의를 열거나 견적·목표를 읽는 것으로 난수·경제·역사를 바꾸지 않는다. 회의에서 내린 결정에만 `village.actions[].council`을 덧붙이며, 기존 저장에는 마이그레이션이나 강제 초기화를 하지 않는다. 기존 수동 외교·이전 모드·생활·물·먹거리·교역 화면을 보존한다.

이번 변경은 새 자원·직업·전투·외교 시뮬레이션이나 주민 직접 조작을 추가하지 않는다. 성능 개선도 주장하지 않는다.

## 검증

- `node tests/council.mjs`: 순수 조회, 세 경제 경로의 실제 차이, 비용 검증·무료 지급 방지, 30일 결산, 결정 도중 저장의 동일 재실행.
- `node tests/council-ui.cjs`: 1440px·390px에서 선택→관찰→일시정지 복귀→결산→저장 복원, 자바스크립트·요청 오류 및 가로 넘침 검사. 촬영본은 `/tmp/everworld-council`에 생성.
- `node tests/winter.cjs`, `node tests/survival.cjs`, `node tests/survival-ui.cjs`: 기존 겨울 경로, 물·식량·물자 보존, 생활 화면의 건설·어로·저장 회귀 확인.
