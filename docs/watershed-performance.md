# 확대 화면의 배경 재사용과 움직임 개선

**v12의 이전 측정 기록입니다.** v13 화면 검증에서 브라우저 프레임 사이의 깊이 복사 실패와 배경 소실을 확인했습니다. 아래 v12 수치는 올바른 화면이 계속 표시된 성능의 증거로 사용할 수 없습니다. 현재는 오프스크린 색·깊이를 셰이더로 복원하며, [v13의 새 측정과 실제 화면](frontier-survival.md)을 참고하세요. 원시 기록은 과거 측정의 재현을 위해 보존합니다.

2026-11-01 · [실행](https://kkhkkh20-bit.github.io/everworld-game/frontier.html?campaign=watershed&v=12) · [원시 기록](watershed-performance.json)

확대 화면에서는 주민과 수레가 움직일 때마다 숲·지형·건물까지 다시 제출했다. 이제 배경의 색과 깊이를 유지하고 움직이는 인물·수레·배를 따로 그린다. 나무 뒤로 지나는 수레의 가림 관계도 유지한다. 실제 지형·건물·선택·카메라가 바뀌면 배경을 갱신하고, 멀리 있는 마을의 공사만 바뀌면 가까운 배경을 재사용한다.

WebGL 2의 호환되는 버퍼에서는 색·깊이를 GPU에서 복사한다. 다른 버퍼 조건은 깊이 셰이더를 사용한다. GPU 복사는 고정한 Three.js 0.160의 프레임버퍼 핸들을 사용하므로 라이브러리를 올릴 때 `tests/scene-depth-cache.cjs`를 함께 확인해야 한다. 두 경로의 색·가림·앞쪽 물체·정적 변경을 실제 픽셀로 검증했다.

화면 품질 자동 모드는 모바일·소프트웨어 GPU에서 해상도와 그림자·먼 나무의 세부를 줄인다. 가까운 원래 모델을 유지하고 인구나 시뮬레이션 계산을 생략하지 않는다. 설정에서 `자세히`로 바꿀 수 있다. 주민과 수레의 화면 좌표를 보간해 고정된 시뮬레이션 틱 사이에서도 움직이게 하고, 멈추면 실제 위치에 맞춰 정지한다. 이 보간은 경제 상태나 난수를 쓰지 않는다.

## 같은 저장과 같은 시야의 측정

컨테이너 4코어, Chromium 154·SwiftShader 소프트웨어 GPU, 브라우저 CPU 4배 제한, 390×844 CSS 픽셀이다. 초기 저장과 900일 진행 저장을 이전 엔진으로 만든 뒤 양쪽에서 같은 파일을 불러왔다. 마을 화면의 확대값 39와 초점도 일치시켰다. 비교 중 발견한 확대 범위가 달랐던 중간 측정은 최종 비교에서 제외했다. 자동 품질 설정의 변화도 아래 결과에 포함되므로 순수한 캐시 하나의 효과로 설명하지 않는다.

| 시나리오 | 이전 p95 rAF 간격 | 수정 후 p95 rAF 간격 | 수정 후 실제 진행 | 수정 후 장면 갱신 |
|---|---:|---:|---|---:|
| 초기 마을 · 3배속 | 233.3ms | 49.9ms | 6.19초 동안 7.4일 | 171회 |
| 900일 마을 · 3배속 | 150.1ms | 33.4ms | 6.22초 동안 7.5일 | 173회 |

rAF 간격은 전체 장면의 FPS가 아니다. 장면 갱신 횟수는 해당 표본에서 실제로 배경·이동 물체 합성을 제출한 횟수다. 초기 마을에서는 배경을 15번, 900일 마을에서는 11번 다시 만들었다. 나머지 화면 갱신은 배경을 재사용했다.

두 저장의 정지한 전체 지도는 약 6초 표본에서 장면 재렌더 0회, 긴 작업 0회였다. 지도 이동의 가장 긴 작업은 이전 약 874/867ms에서 약 318/339ms로 줄었지만, 확대 범위 전환 등에는 지연이 남는다. 실제 휴대폰에서 같은 결과나 모든 상황의 무지연을 보장하지 않는다.

`tests/valley-performance.cjs`는 실제 표본 시간·진행 일수·rAF·긴 작업·장면 갱신·배경 재생성을 함께 남긴다. 성능 측정은 다른 무거운 검사와 병렬로 실행하지 않았다. 관련 PC·모바일 UI, 이전 지도 렌더 예산, 주민 활동, 저장과 10개 세계 회귀 검사도 함께 유지한다.

```sh
VALLEY_PERF_OUT=/tmp/valley-before node tests/valley-performance.cjs
VALLEY_PERF_FIXTURES=/tmp/valley-before VALLEY_PERF_OUT=/tmp/valley-after node tests/valley-performance.cjs
```

전후 비교는 이전 소스를 먼저 실행하거나 읽기 전용 소스 폴더를 `VALLEY_PERF_SOURCE`로 지정한다. 같은 입력 저장뿐 아니라 카메라 초점·확대값과 그래픽 조건도 확인한다.
