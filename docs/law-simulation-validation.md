# v1.3 법률 시뮬레이션 검증 — 2026-10-15

## 목적
왕국 법전이 실제 범죄, 수사, 처벌에 영향을 주는지 점검하고, NPC의 범죄 결정과 치안 통계의 비현실적 쏠림을 줄인다.

## 시험 방식
- 현재 main의 규칙 엔진을 직접 실행하고, 플레이어 개입 없이 시드 10개를 각각 180게임일(4,320시간) 진행
- 확인 항목: 인구, 범죄 행위, 법 개정, 체포/유죄, 치안 지수, 살아 있지 않은 사람의 공직 점유 여부, 합법 행위에 대한 잘못된 유죄 처리
- 유죄 판정은 현재 간소화된 '치안대 증거 조사 + 체포' 모델이며, 실제 법원/정식 재판은 미구현

시드·성격과 법집행 수준에 따라 범죄가 상당히 다른 양상을 보인다. 다만 이 수치는 실제 중세 범죄율을 대표하는 통계가 아닌 가상 게임 엔진 내부 수치이다.

## 오류 회귀 테스트
- 범죄 뒤에 법률이 개정되더라도 사건에 기록된 벌금·구금은 범행 시점 규정을 사용함
- 합법으로 변경된 사기 행위는 형사 사건/불법 범죄 통계에 포함되지 않음
- 신고되지 않은 피해는 '실제 행위'로 기록되지만 자동으로 사건 수사가 시작되지 않음
- 국고 횡령 유죄 처리 시 배상, 벌금, 구금, 공직 해임이 적용됨
- 위 10개 세계에서 합법행위에 대한 유죄 처리나 사망자의 공직 점유가 관측되지 않음

## 아직 현실성이 부족한 부분
1. 치안대가 사건의 숨은 실제 범인을 일정 확률로 찾아내는 것은 범죄 현장·증언·알리바이를 실제 객체로 분석하는 과정과 다르다.
2. 정식 재판, 오판 후 항소, 구금시설의 수용 능력, 살인죄 재판, 실제 징역 연차 등은 간소화되어 있다.
3. 배상은 피해액과 가해자의 현금잔고까지만 우선 지급하며 압류/장기채권이 아직 없다.
4. 법률이 달라져도 생활/거래/계약 자체에 미치는 영향은 제한적이다.
5. 범죄의 신고율·실제 피해율·수사 검거율이 현실의 어떤 특정 시대/국가와 일치한다고 주장할 수 없다.

## 다음 검증 단계
- 법원/재판관 또는 판결 역할 분리
- 목격·증언·물증·알리바이 시스템을 실제 NPC 기억에 연결
- 법률 규정 변경이 NPC의 위험 계산과 경제 생활에 미치는 영향 비교실험
- 사건별 경찰 인력 배치, 범죄 예방 효과 및 피해 회복 확인
