# 산들대륙 — 넓은 지도와 접히는 UI

이번 요청은 더 넓은 맵과 실제 세력, 지도를 가리지 않는 화면이다. 이전 230×195 지형에서 670×550으로 확대했다. 관찰하는 정착지는 26곳이며 버들나루만 외부 길과 보호자 없이 시작한다. 나머지 25곳은 해오름 상단연맹·흑철 변경백령·청송 삼림동맹·금빛 평원공국·남해 자유도시의 다섯 세력으로 연결된다.

각 세력은 중심 도시와 소속 마을을 갖는다. 새 세계의 소속 마을은 수확의 8%를 실제 곡물로 운송해 조공한다. 보호자는 여유 비축이 있을 때 식량을 지원하고 기존 전쟁 규칙에 따라 실제 병력을 동원해 방어를 돕는다. 같은 세력 안에서는 경작권 전쟁을 하지 않는다. 세력 사이에 전쟁이 나면 양쪽 소속 마을의 교역과 통행도 영향을 받는다. 버들나루가 보호 제안을 수락하면 보호자의 세력에 편입되고 수확의 12%를 조공한다. 진행 중인 원정의 상대와 같은 세력이 되면 원정을 중단하고 생존 병력과 보급이 실제로 귀환한다.

지역과 지역을 잇는 길을 추가했다. 각 마을은 기존 생산·운반·소비·저장·유지·건설·외교 규칙으로 돌아간다. 넓은 지도에서 가까운 공급처부터 실제 경로 거리를 비교하고, 원정은 왕복 거리만큼 추가 식량을 준비해야 한다. 전쟁 횟수를 맞추기 위해 사건을 생성하지 않는다.

지도 바탕색과 점선은 살아 있는 정착지에 가까운 쪽으로 나눈 **세력 영향권**이다. 모든 땅의 법적 소유나 실제 경작 면적이라는 뜻은 아니다. 실제 생산에 영향을 주는 경작지 소유는 별도의 현장 깃발과 기존 경작권 데이터로 표시한다. 보호자가 사라져 관계가 끝나거나 정착지가 비면 영향권을 다시 계산한다.

## 화면

- 기본 화면에서 정착지 설명 카드·세 개 사건 카드·상시 자원 패널을 제거했다. 위에는 시간 조작, 아래에는 우리 마을·이야기·세력 지도·마을 운영·화면 숨김만 있다. 큰 상세 창은 선택할 때만 열린다.
- 중요한 새 사건 알림은 한 줄로 잠깐 표시하고 닫거나 10초 뒤 사라진다. 과거 사건을 상시 알림으로 다시 띄우지 않는다. 사건이 생겼다고 상세 창을 자동으로 열지 않는다.
- 대륙 전체 보기에서는 다섯 세력의 중심 이름과 우리 마을만 표시한다. 확대하면 개별 마을 이름이 나타난다. 전체 지도에서 주요 이름표가 겹치면 연결선을 따라 조금 위로 배치하고, 그 외 겹치거나 조작 막대·열린 창 아래에 들어가는 이름표는 숨긴다.
- 상단 ✦로 전체 지도, 드래그로 이동, 휠·두 손가락으로 확대한다. `세력·지도`의 작은 대륙 지도와 세력별 지역 이동 버튼으로 먼 곳을 찾아간다. 영향권 색상은 우측 깃발 버튼으로 끄고 켠다.
- `화면 숨김` 또는 H로 UI를 숨긴다. `메뉴 표시`나 ESC로 복원한다. 숨긴 상태에서도 시뮬레이션과 지도가 계속 움직인다.
- 일시정지 뒤 카메라 이동까지 끝나면 렌더 호출과 인물 갱신을 쉬며, 카메라·영향권 표시·지도 탐색은 경제와 RNG를 바꾸지 않는다. 전체 지도에서는 실제 수레 위치를 점으로 표시하고, 확대하면 수레와 작업조를 자세히 보여준다. 반복 나무·바위는 묶어서 그린다. FPS 개선을 측정한 결과는 아니다.

## 저장과 검증

저장 키 `everworld_valley_v2`를 그대로 사용한다. 6개 마을인 기존 저장은 시간·인구·재고·공사·기존 기록을 유지하고 주변 20개 마을을 관찰 대상으로 추가한다. 추가 인구는 인구 회계의 기준에 포함한다. 기존 마을의 조공 계약을 새로 부과하지 않으며, 새로 관찰한 마을에는 관찰 전 사건 기록이 없음을 기록한다. 확장은 한 번만 적용한다. 예전 v1과 직접 조작 모드도 유지한다.

- `tests/valley.cjs`: 기존 인과·경제·전쟁 회귀 검사.
- `tests/valley-regions.cjs`: 26곳의 실제 생산·교역, 다섯 세력·조공·지원, 세력 내부 전쟁 방지, 보호 편입과 물자 보존, 900일 인구·재고 회계, 기존 저장 확장의 보존과 중복 방지.
- `tests/valley-ui.cjs`: PC·모바일·가로 화면의 접힌 UI, 기본 조작 막대 면적 합계 20% 미만, 원거리 이동과 이름표 단계, 관찰의 상태 불변, 정지 화면의 그리기 중단, 정책·기록·저장 복원. 이 면적 검사는 조작 막대의 사각형 합계이며 지도 이름표와 사용자가 연 상세 창은 포함하지 않는다.

전투는 기존 집계 원정 모델이며 모든 병사의 개별 전술은 없다. 영향권은 정착지 위치에 따른 관찰 표시이고, 넓은 세계에서도 모든 땅을 개발하거나 모든 외교 제도를 다루는 모델은 아니다.
